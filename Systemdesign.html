1. How to Start Any System Design Interview

Story: Like entering a hospital—you first talk to receptionist.

What breaks: If you skip → wrong treatment → wrong system.

Math:
1M users × 10 req/day = 10M/day ≈ 115 req/sec

Questions:

  • Scale?
  • Read vs Write?
  • Latency?
  • Consistency?
  • Availability?

Say: “Based on this I assume X, Y, Z—shall I proceed?”

USER → SERVER → DB

USER → LB → APP → CACHE → DB

Tradeoff: Ask questions vs jump coding

// WRONG
app.MapGet("/", () => "Hi");

// RIGHT
builder.Services.AddScoped();

Scale: 100 → 1 server → 1M → cache + LB

Interview Script:
"Let me clarify requirements before designing."

Failure: Wrong assumptions → redesign

Memory: Interview = diagnose before treatment
